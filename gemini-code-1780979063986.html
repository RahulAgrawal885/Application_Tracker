🔗 Connect to Google Sheets

Your data will live in a Google Sheet you own — synced across every browser and device, automatically backed up.

One-time setup (5 minutes):
1. Open Google Sheets → create a new blank spreadsheet, name it anything.
2. Click Extensions → Apps Script.
3. Delete all existing code, paste the contents of apps_script.gs (the file delivered alongside this dashboard).
4. Click Save (floppy disk icon).
5. Click Deploy → New deployment → type: Web app.
6. Set Execute as: Me and Who has access: Anyone → click Deploy.
7. Authorise when prompted, then copy the Web app URL it shows you.
